    Notes

    Each segment is drawn as a polyline whose length is proportional to its sequence length and whose thickness follows read depth — the same convention Bandage uses. The bases-to-pixels scale is calibrated per graph, so a phage and a chromosome are both legible; Settings can pin it instead. Links attach to the correct end of each polyline according to their orientation signs.
